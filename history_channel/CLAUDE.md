# Archive Tales (history_channel) — инструкция для Claude Code на сервере

Документальные ролики (~15 мин, EN) из подлинных архивных изображений. Отдельный проект от детских каналов
в корне репозитория — здесь работать только внутри `history_channel/`.

Главное отличие от автоподбора: **фото выбираются глазами**. Ты (Claude Code) смотришь листы кандидатов
инструментом Read и вписываешь выбранные ref в `episode.yaml`. Именно так получились лучшие выпуски
(`1918-flu-curated`, `plague`).

## Безопасность и права (не нарушать)

- Ключи API лежат только в `history_channel/.env` (в .gitignore). Не печатать их, не коммитить, не вставлять в ответы.
- Не обходить капчи, Cloudflare и другие проверки на ботов (LoC иногда их показывает — тогда пропустить источник).
- Лицензии только: Public domain, CC0, CC BY, «No known restrictions». NC / ND / SA — нельзя (канал монетизируется).
- Газеты: страницы до 1929 года; Papers Past с пометкой «not available for commercial use» — нельзя.
  NYT — только для фактов и цитирования заголовков, сканы NYT не показываем.
- Никакой генерации людей/событий ИИ. Разрешено: параллакс, колоризация (сначала показывается оригинал), карты, кадрирование.

## Порядок работы над выпуском («подбери фото для episodes/smallpox»)

```bash
cd history_channel && source .venv/bin/activate
git pull --rebase
python run.py episodes/<ep> candidates            # все сцены (или: candidates <scene_id> <scene_id>)
```

1. Для каждой сцены открыть `episodes/<ep>/candidates/<scene>.md` (текст сцены + таблица) и листы
   `<scene>_01.jpg`, `<scene>_02.jpg`… (Read показывает картинку; номер в жёлтом квадрате = номер в таблице).
2. Выбрать фото, которые **показывают то, о чём говорит текст сцены**, по количеству ≈ 1 фото на 6–7 с речи
   (130 слов в минуту). Отбраковывать:
   - не тот период (современные фото, если сцена не про «сегодня»), не та страна/болезнь/событие;
   - дубли одного снимка (разные сканы, кропы, раскраски) — оставить лучший скан;
   - маленькие (< 900 px по меньшей стороне), сильно повреждённые, с водяными знаками, обложки книг, схемы, гербы;
   - сомнительные лицензии (если в таблице пусто или NC — не брать).
3. Ориентация: если снимок лежит на боку — `rotate: 90` или `rotate: -90` (по часовой = отрицательное).
   Вертикальные фото допустимы (рендер сделает фон/наезд), но в монтаж пролога лучше брать горизонтальные.
4. Записать в `episode.yaml` в нужную сцену, в том порядке, в каком фото должны идти:
   ```yaml
   images:
     - {file: "curid:25513204"}
     - {file: "met:396158", colorize: true}          # не больше 1 колоризации на сцену
     - {file: "aic:7385", match: "the doctors wore"}  # показать во время этой фразы
     - {file: "curid:104910096", rotate: -90}
   ```
   Ref берутся из таблицы как есть: `curid:N` (Commons), `met:N`, `aic:N`, `cleveland:N`, `smithsonian:…`,
   `europeana:…`, `wellcome:…`. Если хороших фото мало — можно оставить строку `- {query: "...", count: 2}` для автоподбора
   или добавить в сцену `candidates: ["другой запрос", ...]` и перезапустить `candidates <scene>`.
5. Газеты эпохи (сильно оживляют ролик):
   ```bash
   python run.py episodes/<ep> research      # по блоку research: в episode.yaml → research/newspapers.md
   ```
   - Papers Past (Новая Зеландия) ищется без ключа; в md у каждой статьи готовая строка
     `clip: {paperspast: OID, areas: [...]}` → вставить в images сцены: `- {paperspast: "LT19181122.2.57", areas: [1, 2], match: "..."}`.
   - Chronicling America (США, до 1929): `- {newspaper: "<url картинки страницы, поле page image>", date: "1918-10-12", paper: "...", page_url: "<ссылка>", crop: [x0, y0, x1, y1]}`
     (crop — доли страницы 0..1; скачать страницу, посмотреть Read и вырезать заметку/заголовок).
   - Заголовки и цитаты из газет можно вставлять в `quote:` сцены с указанием газеты и даты.
6. Факт-чек: каждое утверждение в narration сверить с `factcheck.md` выпуска; новые факты — с источником.
   Подписи к фото должны соответствовать реальности (дата, место); если архив пишет «c. 1920», а сцена 1918 — не выдавать за 1918.
7. Сборка и проверка:
   ```bash
   python run.py episodes/<ep> fetch          # скачивание (меняются только изменённые сцены)
   python run.py episodes/<ep> preview        # быстрый черновик
   python run.py episodes/<ep> review         # листы того, что реально попало в ролик → посмотреть Read
   python run.py episodes/<ep> render         # финал (долго; не параллельно с другими рендерами — 15 ГБ RAM)
   ```
8. Закоммитить `episode.yaml`, `candidates/` (листы небольшие — их можно смотреть и из чата), `research/*.md`
   (media/build/audio в .gitignore) и запушить. В коммите — что выбрано и почему отброшено подозрительное.

## Структура

- `run.py` — шаги: fetch, voice, preview, render, publish, review, research, candidates, upload.
- `pipeline/archives.py` — поиск по архивам; `candidates.py` — листы; `fetch.py` — скачивание/вырезки газет;
  `select.py` — эпоха, дубли, CLIP; `render.py` — монтаж; `maps.py` — карты; `music.py` — музыка кодом; `research.py` — газеты.
- `episodes/<ep>/episode.yaml` — сценарий; `factcheck.md` — источники фактов.
- Идеи тем: `TOPICS.md`.

Принятые решения (не пересматривать без пользователя):
- Формат: «биография болезни» (происхождение → лечение → победа → что сейчас) и «истории-случаи»; плюс мировая история. EN, ~15 мин.
- Ручной подбор фото лучше автоматического — пользователь сравнил. Нужно разнообразие архивов, не только Commons.
- ИИ-генерации минимум: параллакс (Depth Anything V2 Small), колоризация DDColor — `colorize_per_scene: 1`, сначала оригинал.
  ИИ-анимация — только позже и через платный сервис, с пометкой о синтетическом контенте.
- Музыка только кодом (`music.py`), голос Kokoro (bm_george); в описании указать синтетический голос.
- В описании ссылка на каждое фото с таймкодом (publish.py делает сам).
- Карты рисуются кодом (Natural Earth), газеты — вырезками со ссылкой, только до 1929 и без NC.
- Детские каналы и Sacred Drift на этом же сервере: не запускать рендер параллельно с их рендерами (проверить `ps aux | grep -E "ffmpeg|remotion|render"`).
