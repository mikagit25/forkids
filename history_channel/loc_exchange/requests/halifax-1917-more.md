# Halifax 1917 — more photos needed (request 2, 21.11.2026)

(append; same format as before). LoC: "No known restrictions" only. **Nova Scotia Archives** (archives.novascotia.ca,
Halifax Explosion collection) is very welcome: `source: nsarchives`, `id`, `image` (largest JPEG), `page_url`, `rights`
(copy the rights line; only public domain / no known restrictions). If a site only lets a browser download the
image, download it and upload via https://medmind.pro/files → 📷 Archive Tales фото → other (file name must contain the id).

"Halifax fire department", "Intercolonial Railway Halifax", "North Street station Halifax", "Richmond Halifax 1917",
"Halifax Relief Commission", "Hydrostone 1920", "Halifax courthouse", "Mont-Blanc", "Imo whaler".
