# Пайплайн исторических видео из архивов

Из одного файла `episode.yaml` (сценарий + запросы к архивам) собирается готовый ролик для YouTube:
архивные фото с объёмным движением камеры (параллакс), главы, цитаты из первоисточников, подписи
источников на экране, озвучка, фоновая музыка, синтезированная кодом, субтитры, главы для YouTube,
обложка и описание, где каждое фото указано с таймкодом и ссылкой на оригинал.

## Принцип: минимум генерации, максимум подлинности

- **Параллакс** (Depth Anything V2 Small, Apache-2.0): нейросеть только оценивает глубину, пиксели
  подлинного снимка сдвигаются с разной скоростью. Ничего не дорисовывается, отметка YouTube
  «изменённый контент» не нужна (это спецэффект камеры). Без модели — обычный Ken Burns.
- **Колоризация** (DDColor, Apache-2.0) только для кадров с `colorize: true`: сначала зритель видит
  подлинное чёрно-белое фото, затем переход в цвет, в подписи «Digitally colorized». В описании
  отмечено, что цвета — оценка алгоритма, а не исторические данные. Использовать изредка: 2–4 кадра на выпуск.
- **Цитаты**: `quote` в сцене показывает карточку с цитатой из первоисточника, пока диктор её читает.
  Только тексты в общественном достоянии (для США: опубликованные до 1929 года) и только проверенные.
- **Музыка** `music: {generate: true, seed, mood}`: эмбиент-подложка синтезируется кодом (numpy),
  без сэмплов и ИИ, тот же seed даёт ту же музыку. Настроения: `somber`, `tense`, `hopeful`.
  Можно указать и свой файл: `music: path/to/track.mp3`. Под голосом музыка автоматически приглушается.
- **Проверяемость**: в описании каждое фото с моментом появления и ссылкой на оригинал в архиве;
  полный список с лицензиями — `build/sources.md` (его можно опубликовать на сайте и указать
  ссылку в `sources_url` в `channel.yaml`, тогда описание сошлётся на него, если не влезет в 5000 знаков).

Отдельный проект внутри репозитория, ничего из детских каналов не использует и не трогает.

## Установка (один раз)

Сервер (Ubuntu/Debian):
```bash
cd /opt/kids_channel && git pull
cd history_channel
bash setup_linux.sh
```

Mac (macOS 13+): `bash setup_mac.sh` (ставит Python 3.12 и ffmpeg через Homebrew).

Скрипт поставит Python 3.12 и ffmpeg через Homebrew, создаст окружение, скачает модель озвучки (~350 МБ) и шрифты.

## Сделать выпуск

Все команды из папки `history_channel`.

```bash
source .venv/bin/activate
python run.py episodes/1918-flu fetch     # 1. найти и скачать архивные фото
# 2. посмотреть episodes/1918-flu/contact_sheet.html (скачать к себе и открыть в браузере)
python run.py episodes/1918-flu voice     # 3. озвучка (озвучка уже есть в папке audio/)
python run.py episodes/1918-flu preview   # 4. быстрый черновик 540p (~2 мин)
python run.py episodes/1918-flu render    # 5. финал 1080p
python run.py episodes/1918-flu publish   # 6. обложка + описание
```

Или всё сразу: `python run.py episodes/1918-flu all`.
Результат в `episodes/1918-flu/build/`: `1918-flu.mp4`, `thumbnail.jpg`, `description.txt`, `sources.md`, `subtitles.en.srt`, `chapters.txt`.

Время: ~15-минутный выпуск — около 1–1,5 часа рендера 1080p на 2 ядрах (параллакс и колоризация
считаются один раз на фото и кэшируются). Запускать последовательно с другими тяжёлыми задачами сервера.
Без параллакса быстрее: `python run.py episodes/1918-flu render --no-parallax`.

## Где работает человек (это и делает канал «аутентичным» для YouTube)

1. **Тема и сценарий.** Сценарий пишется в `episode.yaml`, по сценам. Каждая сцена: текст, запросы для картинок, необязательные глава и дата.
2. **Фактчек.** `factcheck.md` рядом со сценарием: каждое утверждение отмечается перед рендером.
3. **Отбор картинок.** В `contact_sheet.html` зелёные будут в видео, бледные это запасные. Чтобы заменить: в `manifest.json` поставить `"use": false` у плохой и `"use": true` у запасной, затем снова `render`. Повторный `fetch` ваш выбор не трогает (`--refresh` начнёт заново).
4. **Просмотр и публикация.** `upload` загружает ролик как **приватный**; публикуете вы в YouTube Studio.

## Права на изображения

Код берёт только: public domain, CC0, CC BY, «No known restrictions» (Библиотека Конгресса).
NC (некоммерческие), ND (без изменений) отбрасываются всегда, CC BY-SA по умолчанию тоже
(переключатель `ALLOW_SHARE_ALIKE` в `pipeline/archives.py`). Источник и лицензия каждой
картинки показываются в кадре и попадают в описание.

Архивы: Wikimedia Commons (основной, там зеркала фото Библиотеки Конгресса, Национального архива США,
CDC и др.), Wellcome Collection (история медицины), Библиотека Конгресса напрямую.
loc.gov иногда отвечает скриптам проверкой Cloudflare; тогда он пропускается, остальные архивы работают.

## Озвучка

По умолчанию Kokoro: бесплатно, локально, лицензия Apache-2.0 (коммерческое использование разрешено).
Голоса: `bm_george`, `bm_lewis`, `bm_daniel` (британские мужские), `am_michael`, `am_onyx` (американские),
`bf_emma`, `af_heart` (женские). Испанский тоже есть (`ef_dora`, `em_alex`), арабского нет.
Для арабского или другого качества: `backend: openai` + переменная `OPENAI_API_KEY`.
Озвучка кэшируется по предложениям: правка одной фразы переозвучивает только её.

## Загрузка на YouTube (по желанию)

Нужен OAuth-клиент Google Cloud с включённым YouTube Data API v3 (тип Desktop app), файл `client_secret.json`
в корне проекта. Первый запуск `python run.py episodes/1918-flu upload` откроет браузер для входа.

## Новый выпуск

Скопируйте папку `episodes/1918-flu` в `episodes/<новая-тема>`, удалите в ней `media/`, `audio/`, `build/`,
`manifest.json`, перепишите `episode.yaml` и `factcheck.md`.
