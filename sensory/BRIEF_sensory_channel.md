## 1. Что мы разобрали (Hey Bear Sensory, окт. 2026)

~3,97 млн подписчиков, всего 95 видео, но просмотры огромные: 381 млн, 331 млн, 278 млн, 241 млн, 181 млн, 169 млн и т.д.
Мало роликов — много просмотров. Значит, выигрывает **качество формата и пересматриваемость**, а не количество.

### Три «столпа» канала

| Формат | Примеры (просмотры) | Длина | Суть |
|---|---|---|---|
| **Танцующие фрукты/овощи** (главный хит) | Smoothie Mix 381M, Fruit Salad Counting 1–10 331M, Funky Veggies Extended 278M, Disco Fruit Party 241M, Birthday Dance Party 181M | 10–25 мин (+ мини-версии 2–3 мин, + миксы 1 ч) | Персонажи с лицами качаются/прыгают строго в бит весёлой музыки |
| **High contrast / визуальная стимуляция** | Ранние безымянные ролики 7–71M, Springtime Black & White 46M, Rainbow Summertime 50M | 12–45 мин | Простые яркие фигуры на чёрном фоне, медленно движутся, для новорождённых |
| **Колыбельные / сон** | Mindful Moon & Sleepy Stars 65M, Lanterns 40M, Under the Sea 45M, Coral Reef Cam 10M | 25 мин – 2 ч | Медленные плавающие объекты, тёмный фон, спокойная музыка |

Плюс сезонные выпуски (Хэллоуин 101M, Рождество 91M, лето 169M) — это те же танцы, только персонажи в костюмах.

### Визуальная грамматика (ключевое — это и надо объяснить Claude)

1. **Фон всегда чистый чёрный** (или очень тёмный). Нет сцен, нет пола, нет декораций.
2. **Объекты крупные, по центру, 1–5 штук в кадре.** Ничего мелкого.
3. **Насыщенные цвета + «глянец»**: радиальный градиент + белый блик сверху-слева + лёгкое свечение (glow) вокруг. Выглядит «объёмно», но это 2D.
4. **Лицо = простые кружки**: два больших глаза (белок + чёрный зрачок + белый блик), улыбка-дуга, иногда розовые щёчки. Моргание каждые 3–6 с.
5. **Движение строго по биту**: на каждый удар — squash & stretch (сжатие/растяжение), подпрыгивание, покачивание ±10–15°. Без резких дёрганий.
6. **Медленная смена «номеров»**: один персонаж/группа танцует 8–16 тактов, потом плавная смена (влёт/вылет, zoom, растворение).
7. **Нет речи и текста** (кроме цифр в «счётных» эпизодах) → работает на любом языке мира, это главная причина миллионов.
8. **Музыка**: инструментальная, чёткий бит, 100–128 BPM для танцев; 60–80 BPM для сна.
9. **Мини-«лупы»**: одна и та же структура повторяется — малышам нравится предсказуемость.

### Почему это работает
- Малыш 0–2 года видит контраст и яркие пятна на тёмном фоне лучше всего.
- Синхрон движения с музыкой даёт «гипнотический» эффект → ролик крутят по кругу (длинное время просмотра).
- Без языка → глобальная аудитория.
- Длинные версии (20 мин – 1 ч) родители ставят фоном → watch time.

## 2. Что мы хотим получить

Конвейер, который **из одной аудиодорожки + конфига эпизода** собирает готовое MP4-видео 1920×1080, 30 fps, в описанном выше стиле. Персонажи — **наши собственные** (не фрукты Hey Bear один-в-один, не их имена и не их музыка).

Приоритет форматов:
1. **Dance** — танцующие персонажи в бит (главный).
2. **Counting** — то же + появляются по одному с цифрой 1…10.
3. **High contrast** — фигуры на чёрном, медленно.
4. **Sleep** — луна/звёзды/рыбки, медленно, 30–60 мин (можно лупом).

## 3. Как это сделать кодом (стек)

```
episode.yaml ──► beat analysis (librosa) ──► timeline (сцены по тактам)
                                              │
characters/*.py (векторные персонажи)  ──────►│──► render frames (pycairo / skia) ──► ffmpeg ──► mp4
```

- **Python 3.11**, `pycairo` (или `skia-python`) — 2D-рисование с градиентами и сглаживанием.
- **librosa** — находит BPM, позиции битов (`beat_track`) и сильные доли тактов.
- **numpy** — easing-функции, анимация.
- **ffmpeg** — склейка кадров + аудио. Рендер через пайп (`rawvideo` → stdin ffmpeg), без сохранения PNG.
- Параллельный рендер чанками (`multiprocessing`), потом `ffmpeg concat`.
- Альтернатива, если захочется «3D-глянца»: Blender + Python API. Начинать с 2D.

### Структура проекта
```
sensory/
  CLAUDE.md                 # этот файл
  episodes/fruit_party_01.yaml
  audio/                    # только музыка, на которую есть права
  sensory/
    beats.py                # анализ аудио → список битов/тактов
    easing.py               # ease_in_out, bounce, elastic
    face.py                 # глаза, моргание, улыбка, щёчки
    style.py                # палитра, gloss, glow
    characters/
      base.py               # класс Character: draw(ctx, t, beat_phase)
      berry.py, pear.py, cloud.py, star.py, moon.py ...
    scenes/
      dance.py, counting.py, contrast.py, sleep.py
    timeline.py             # yaml → список сцен со временами
    render.py               # кадры → ffmpeg
  out/
```

### Ключевые алгоритмы
**Фаза бита.** Для времени `t` найти предыдущий и следующий бит → `phase = (t - b_prev)/(b_next - b_prev)` в [0,1). Вся анимация считается от `phase`, не от `t` — поэтому движение всегда точно в музыку.

**Squash & stretch на бит:**
```python
k = math.exp(-phase * 6)            # резкий импульс на ударе, затухает
sy = 1 - 0.18*k ; sx = 1 + 0.12*k   # сплющился на ударе
jump = -abs(math.sin(math.pi*phase)) * 40  # подпрыгнул между ударами
tilt = 12 * math.sin(math.pi * beat_index_parity_phase)  # качание влево/вправо через бит
```
Разным персонажам — сдвиг по фазе (0, 0.25, 0.5 бита) и разные движения, чтобы группа выглядела «живой».

**Глянцевый объект:** тело = path с радиальным градиентом (светлый центр сверху-слева → насыщенный цвет → темнее к краю), сверху белый эллипс-блик с alpha 0.6, вокруг glow (тот же path, размытый/увеличенный с alpha 0.25).

**Глаза:** белок, зрачок смотрит в сторону движения (небольшой offset), блик. Моргание: случайный интервал 3–6 с, длительность 0.15 с (масштаб по Y → 0.1).

**Смена сцен:** каждые 8 или 16 тактов (по `beats.py`), переход 1 такт: старые улетают/уменьшаются, новые влетают с elastic-easing.

### Пример конфига эпизода
```yaml
title: "Fruity Party #1"
format: dance            # dance | counting | contrast | sleep
audio: audio/track_120bpm.wav
resolution: [1920, 1080]
fps: 30
background: "#000000"
scenes:
  - bars: 8   ; cast: [berry]
  - bars: 8   ; cast: [pear, pear]
  - bars: 16  ; cast: [berry, pear, plum]
  - bars: 8   ; cast: [cloud_rainbow]
loop_to_length: "00:12:00"   # растянуть повтором сцен под нужную длину
```

### Два способа делать персонажей (можно смешивать)
- **А. Чистый код** (pycairo): круги, дуги, градиенты. Подходит для радуги, облаков, точек, звёзд, луны, шариков. Рабочий пример — `demo/demo.py` (радуга с лицом + облака в бит; 7 точек прыгают вверх по очереди на каждый бит). Рендер 20 с видео занимает ~10 с.
- **Б. PNG-спрайты**: готовые картинки персонажей (свои, сгенерированные или нарисованные) с прозрачным фоном. Код только двигает их: масштаб/squash, поворот, прыжок, glow (размытая копия спрайта под ним). Лицо можно рисовать кодом поверх PNG, чтобы оно моргало. Для сложных фруктов/животных это быстрее, чем рисовать кодом.

### Готовые «простые» сценарии (каждый = одна функция `scene_xxx(ctx, t)`)
- точки/шарики прыгают по очереди в бит (слева направо, потом обратно, потом все вместе);
- радуга/солнце/облака с лицом качаются, облака прыгают в противофазе;
- фигуры (круг, звезда, сердце) появляются в центре на сильную долю, меняют цвет;
- счёт: на каждый такт добавляется ещё один объект + цифра;
- high contrast: белые/цветные фигуры на чёрном, медленно вращаются;
- сон: звёзды мерцают медленно, луна плавно покачивается.

## 4. План работы для Claude (по шагам, каждый — проверяемый)

1. **Каркас + один кадр.** `render_still(scene, t)` → PNG одного глянцевого персонажа с лицом на чёрном. Я смотрю картинку, правим стиль, пока не будет «как у топовых каналов».
2. **Анимация без музыки.** 5-секундный mp4: персонаж качается с фиксированным BPM 120, моргает.
3. **Синхрон с аудио.** `beats.py` + реальный трек → 30 с видео, движения точно на удары.
4. **Группа + смена сцен** по YAML → 2–3 минутное «мини»-видео.
5. **Набор персонажей** (8–12 штук своих) + сезонные аксессуары (шляпа, колпак, тыква) как отдельный слой.
6. **Форматы counting / contrast / sleep.**
7. **Длинные версии**: склейка/луп до 10–60 мин без перерендера (ffmpeg concat).
8. **Превью-картинка** (thumbnail 1280×720) из того же движка: 2–3 персонажа крупно + яркий цвет.

Правила для Claude: после каждого шага рендерить и показывать мне кадр/короткий клип; не переходить дальше, пока я не подтвердил внешний вид. Стиль важнее функциональности.

## 5. Ограничения (важно, чтобы канал не заблокировали)

- **Не копировать** персонажей Hey Bear (Avocadosaurus, Mindful Moon, Funky Veggies и т.п.), их дизайн, названия, логотип, превью и музыку — это их собственность, будут страйки/Content ID. Берём **жанр и приёмы**, персонажи и имена — свои.
- **Музыка**: только своя, сгенерированная с лицензией на коммерческое использование, или купленная/royalty-free. Классика — сами произведения общественное достояние, но **записи** обычно защищены; можно рендерить классику из MIDI своими инструментами.
- YouTube: ставить «Made for Kids». Политика YouTube против «массового/шаблонного» (inauthentic/repetitive) контента — поэтому каждый эпизод должен отличаться (новые персонажи, тема, трек), а не 100 одинаковых перемонтажей.
- Без резких вспышек и быстрого мерцания (>3 вспышек/с) — это и вредно для детей, и нарушает правила.
